# ArkType Idea Plugin

This is a fork of the ArkType IntelliJ plugin located [here](https://github.com/niklas-wortmann/arktype-idea-plugin).  The original plugin is stale and does not support 2026+ versions of the IDE. The issue is just the version specifier, it actually works fine.

I've raised an issue [here](https://github.com/niklas-wortmann/arktype-idea-plugin/issues/30) and will take down this fork if it ever gets fixed.
